AWS Project - 3 🟡 Application Load Balancer + Auto Scaling Group Architecture
--------------------------------------------------------------------------------

Project Objective :

Implement a highly available AWS architecture using Application Load Balancer (ALB), Target Group, Launch Template, Auto Scaling Group (ASG), and CPU-based Auto Scaling.

The environment should automatically launch new EC2 instances when CPU utilization increases and automatically terminate additional instances when CPU utilization decreases.

✅ Key Learnings 
-----------------
• Launch Template acts as a blueprint for all Auto Scaling instances.
• Target Group performs health checks and forwards traffic only to healthy instances.
• Application Load Balancer distributes traffic across multiple Availability Zones.
• Subnet-level Auto Assign Public IP is recommended for Auto Scaling environments.
• Auto Scaling dynamically increases or decreases capacity based on CPU metrics.
• User Data enables automatic software installation during EC2 launch.
• Activity History can be used to validate Scale-Out and Scale-In operations.
